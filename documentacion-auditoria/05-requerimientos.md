# 05 · Ingeniería de requerimientos derivada del sistema real

## 1. Método y convenciones

Este catálogo convierte capacidades observadas en requisitos trazables. **C** significa comprobado en código/SQL o en el catálogo estructural local; no significa que cada camino se ejecutó en esta auditoría. **I** es una interpretación analítica. **P** es propuesta explícita, no funcionalidad existente. Ver 03 para inventario detallado y 09 para ejecución. Prioridades y criterios de aceptación son formulaciones del analista para el trabajo académico, no compromisos ni reuniones inventados. Deben validarse con el responsable individual del proyecto.

No existe registro/login de cliente público ni un perfil de comprador conectado a Auth; los actores son visitante/comprador invitado, empleado activo y administrador activo. Sistema SQL y desarrollador son actores técnicos cuando corresponde. Los permisos por API concretos se verifican en 08; 'personal autorizado' evita adjudicar a todo empleado cada operación de configuración.

## 5. Dependencias y validación pendiente

- Compra depende de catálogo/receta, disponibilidad, horarios, configuración de entrega y claves del entorno. QR/WhatsApp son auxiliares de comunicación/cobro manual, no confirmaciones bancarias automáticas.
- Confirmar pago depende de reservas válidas; venta física depende de caja abierta; reintegros sobre ventas físicas requieren la caja correspondiente abierta.
- Programación usa revisión y guardas SQL; el cliente lee estado propuesto/confirmado pero no agenda el horario mediante un endpoint público de edición.
- Facturación fiscal, autenticación pública, destinatario estructurado, cálculo de reparto y SLA requieren definición adicional. No se supone que estén a medio desarrollar sólo porque podrían ser deseables.
- Antes de usar estos requisitos como especificación definitiva se deben validar términos con el responsable, distinguir pruebas previas de evidencia actual y acordar criterios cuantitativos de calidad. No se inventaron fechas, equipo ni porcentaje de avance.
